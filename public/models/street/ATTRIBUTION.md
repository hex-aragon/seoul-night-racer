# Original Blender street kit — CC0

The signal mast, three-color lamp housings and visors, pedestrian signal, glass bus shelter, timber bench, branching tree and asphalt aggregate texture were authored for this project in Blender 5.2. Source: `art/build_street.py`, `art/signal.blend`, `art/shelter.blend`, `art/tree.blend`. These original assets and the creation script are dedicated to CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

Exported GLBs preserve separate lamp materials for the real-time signal system. Tree meshes are instanced at runtime. No third-party photographs or samples are used in these models. Road locations and signal timing are fictional game design.
