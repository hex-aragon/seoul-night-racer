# 지도와 지역 모델 출처

24개 추천 코스의 도로 중심선은 © OpenStreetMap contributors의 데이터를 OSRM으로 경로 탐색한 결과입니다.

- [OpenStreetMap 저작권 및 ODbL 안내](https://www.openstreetmap.org/copyright)
- [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- [OSRM](https://project-osrm.org/)
- [도로 데이터와 생성 스크립트](https://github.com/hex-aragon/seoul-night-racer/tree/main/public/maps)

이 폴더의 각 JSON은 원본 경로 좌표, 경로 탐색 URL, 거리와 출처를 포함합니다. 도로 데이터와 파생 도로 데이터베이스는 ODbL 1.0으로 제공됩니다. 수집일: 2026-09-12.

실제 도로의 수평 경로를 게임 좌표로 변환하고 곡선을 부드럽게 보간했습니다. **고도, 차선 수, 해안선, 지형, 건물과 시설물 위치는 게임용으로 재구성했습니다. 도시 전체의 1:1 복제나 실제 운전 안내용 지도가 아닙니다.** 기존 133개 추가 코스는 가상의 아케이드 코스입니다.
